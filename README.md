# RAV — Robô Autônomo de Varejo

Branch criada com o objetivo de integrar a base móvel e o manipulador do robô, visando sua futura utilização em simulações contendo obstáculos e bancadas com objetos, para validação dos algoritmos de navegação, planejamento de trajetória e manipulação de objetos.

Após a integração entre a base móvel e o manipulador robótico, obteve-se a estrutura completa do robô autônomo de varejo, conforme ilustrado nas figuras a seguir.
