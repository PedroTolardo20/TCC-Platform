# RAV - Robô Autônomo de Varejo 
O objetivo deste trabalho é o desenvolvimento de um robô autônomo capaz de navegar e manipular objetos de forma independente em um ambiente que simule operações de varejo.
Para a definição da arquitetura mecânica e funcional do projeto, foi realizada uma análise de soluções semelhantes disponíveis no mercado, buscando identificar referências de desempenho, mobilidade e capacidade de manipulação.

## Modelagem

Após a definição da estrutura do robô, iniciou-se o processo de modelagem mecânica da base móvel e do manipulador robótico.

Para o desenvolvimento do sistema de manipulação, foi utilizado como referência o repositório apresentado abaixo. Entretanto, o modelo URDF do manipulador foi adaptado e modificado para atender aos requisitos específicos deste trabalho, considerando as características mecânicas e funcionais do manipulador proposto.
